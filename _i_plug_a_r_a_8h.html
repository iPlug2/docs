Detailed Description

ARA (Audio Random Access) support for iPlug2 VST3 plug-ins.

ARA is an extension of a companion plug-in format (here VST3), not a standalone format. Define ARA_API at project level in addition to VST3_API to build an ARA-enabled VST3 plug-in.

A minimal ARA plug-in subclasses IPlugARADocumentController (typically also providing a custom ARA::PlugIn::PlaybackRenderer via doCreatePlaybackRenderer()) and sets ARA_DOC_CONTROLLER_CLASS in config.h to the name of that subclass. See Examples/IPlugARAExample.
