Detailed Description

Base class for an iPlug2 ARA document controller.

Provides default no-op implementations for the hooks that ARA::PlugIn::DocumentController leaves pure virtual, so a subclass only needs to override what it actually uses. Plug-ins that persist analysis results must override the archiving hooks.
