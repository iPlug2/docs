Detailed Description

ARA VST3 glue - included by IPlug_include_in_plug_src.h when ARA_API is defined alongside VST3_API.

Do not include this file directly. Generates the ARAFactory from config.h macros and provides the ARA::IMainFactory class that is registered with the VST3 module factory under kARAMainFactoryClass.

◆ ARA_HAS_ANALYZEABLE_CONTENT_TYPES

#define ARA_HAS_ANALYZEABLE_CONTENT_TYPES   0

Comma separated list of ARA::ARAContentType values that the plug-in can analyze and then export to the host, without enclosing braces, e.g.

#define ARA_ANALYZEABLE_CONTENT_TYPES ARA::kARAContentTypeNotes, ARA::kARAContentTypeKeySignatures The list is used to initialize an array, so if defined it must not be empty - leave the macro undefined if the plug-in does not analyze any content. Hosts use this both to decide which content to request and to show the plug-in's capabilities in their UI.
